# Bimo Transport Prototype

Prototype statis berbasis HTML yang saling terhubung.

## Halaman

- `index.html` - Beranda dan profil singkat
- `armada.html` - Jenis bus, fasilitas, dan daftar harga
- `mitra-testimoni.html` - Partner dan testimoni
- `kontak.html` - Kontak dan form pemesanan

## Menjalankan Lokal

Jalankan server statis dari folder project, lalu buka `http://localhost:8000`.
